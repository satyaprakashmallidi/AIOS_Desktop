# AIOS Connectors — Supabase backend

Tiny relay service that brokers all Composio API calls from the AIOS Desktop
app. The master Composio API key lives only here, never in the desktop app.

## What's in this folder

- `migrations/0001_init.sql` — `device_users` + `device_connections` tables.
- `functions/aios-relay/` — the desktop app's only backend. Per-user CRUD
  for connections, scoped to a `device_user_id` UUID generated by AIOS on
  first launch.
- `functions/composio-webhook/` — Composio fires this when OAuth flows
  complete. Updates connection status so the desktop app's polling sees it.

## One-time setup

You'll need the [Supabase CLI](https://supabase.com/docs/guides/local-development/cli/getting-started)
installed (`npm i -g supabase` or `brew install supabase/tap/supabase`).

```bash
# 1. Link this folder to your Supabase project (only once per machine)
cd supabase
supabase link --project-ref <your-project-ref>

# 2. Push the migration to create the tables
supabase db push

# 3. Set the secrets the relay needs
supabase secrets set COMPOSIO_API_KEY=<your-composio-api-key>
supabase secrets set COMPOSIO_WEBHOOK_SECRET=<your-composio-webhook-secret>

# 4. Deploy both functions
supabase functions deploy aios-relay
supabase functions deploy composio-webhook --no-verify-jwt

# 5. In your Composio dashboard, configure the webhook URL:
#    https://<your-project-ref>.supabase.co/functions/v1/composio-webhook
#    Copy the webhook secret it gives you back into Supabase secrets (step 3).
```

## Endpoints

All endpoints require `Authorization: Bearer <device_user_id>` (a v4 UUID).

| Method | Path | Body / Query | Returns |
|--------|------|---|---|
| POST | `/register` | `{ os, appVersion }` | `{ entityId, alreadyRegistered }` |
| GET | `/connections` | — | `{ connections: [...] }` |
| POST | `/connections/:service/initiate` | — | `{ redirectUrl, connectionId }` |
| DELETE | `/connections/:connectionId` | — | `{ ok: true }` |
| GET | `/mcp-config` | — | `{ mcpUrl, mcpAuthHeader, label }` |

## Smoke test

After deploying, this should return `{ "connections": [] }` for any
fresh UUID:

```bash
curl https://<your-project-ref>.supabase.co/functions/v1/aios-relay/connections \
  -H "Authorization: Bearer 00000000-0000-0000-0000-000000000000"
```

## Local development

```bash
supabase functions serve aios-relay --env-file .env.local --no-verify-jwt
```

Where `.env.local` contains:
```
COMPOSIO_API_KEY=...
SUPABASE_URL=https://<your-project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=...
```

The local function is then reachable at `http://localhost:54321/functions/v1/aios-relay`.
